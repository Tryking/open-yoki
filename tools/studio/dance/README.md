# dance/：让你的角色跳舞

| 命令 | 服务 | 什么时候用 | 花费 |
| --- | --- | --- | --- |
| `driver <dance.mp4>` | 不用（离线） | 最先跑：这段驱动视频好不好用？ | 免费 |
| `frame <char> <video> [--box t,b,l,r]` | 给了 `--box` 就不用，否则让 OpenRouter 找出舞者 | 预览头到膝盖的 9:16 裁切 | 免费 / <$0.01 |
| `bind <char> <look> <dance.mp4>` | fal，可灵 3.0 动作控制 + 绑脸 | **默认**：舞步必须一步不差，全身也行 | pro 档约 $0.168/秒，`--std` $0.126/秒；10 秒约 $1.7，约 6 分钟 |
| `o3 <char> <look> <dance.mp4>` | LibTV，可灵 O3 多参考 | 半身镜头里脸最好看；舞步跟得松一些 | LibTV 积分，每 10 秒要 10–15 分钟 |
| `viggle <char> <look> <dance.mp4>` | Viggle | 快速换人，透明背景 | Viggle 积分 |

每次生成最后都会自动验脸（`check/face.mjs`）；加 `--no-check` 跳过。`--dry-run` 打印计划和花费。

## 我们踩坑学到的

| 试过什么 | 结果 |
| --- | --- |
| 全身动作迁移，不帮脸 | 动作没问题，脸难看：脸只有几十个像素，变成一张“平均脸”（眼睛变小、妆变浓、眼神空）。开高质量模式也救不回来。 |
| 事后换脸 / 视频改脸 | 被审核拒掉，或者几乎没变化。 |
| 框到头到膝盖 + 可灵 O3，参考依次是主脸 → 造型照 → 站姿全身 + 驱动视频 | 脸好，造型也好。这就是 `o3` 这条路。 |
| 可灵 3.0 动作控制，**绑定脸**（主脸 + 两张 3/4 侧脸） | 就算全身拍到脚，眼睛、刘海、脸型也都回来了。这就是 `bind` 这条路，默认用它。 |

规矩：
- **站着跳。** 坐着“跳舞”看起来像出了故障。驱动视频要：站着、正对镜头、不转圈、不甩头发。
- **靠挑驱动视频，别靠提示词。** 动作迁移会照搬舞者的表情（嘟嘴、O 型嘴、龇牙咧嘴）；提示词里写“抿嘴笑”压不住。舞者面无表情，出来的脸也面无表情。挑一个会自然笑、自然眨眼的舞者。大家认得的热门舞比原创舞好。
- 可灵 O3 一次最多 10 秒；更长的舞会被切成几段，接缝处可能跳一下。看看接缝。
- 有些裁法会让可灵不说原因直接报 “generation failed”；`o3` 会自动换成更松的裁法，再不行就不裁。失败扣的积分一般会退回来。
- 手快速动的时候，每个模型都会糊。验脸只看脸；手要靠人眼看。
- 音乐：默认把舞蹈视频自己的音轨放回去（用 `--music` 换掉）。那段音乐的版权你自己负责。
